# Píllalo Puerto Rico · Android

Instalador oficial de **Píllalo Puerto Rico** para Android.

Dos cartas, un símbolo boricua en común. Encuéntralo antes que tus panas y la carta es tuya. Juega contra la compu o abre una sala de hasta 8 jugadores, con voz.

## Descargar

**[Descargar Pillalo.apk](https://github.com/fadhelcarlos/pillalo-android/releases/latest/download/Pillalo.apk)** · siempre la versión más reciente

También puedes descargarlo desde [pillalo.live](https://pillalo.live/#descargar), donde hay una guía paso a paso.

## Instalar

1. Abre el archivo `Pillalo.apk` que descargaste.
2. Android pregunta si permites instalar apps desde tu navegador. Toca **Ajustes**, activa **Permitir desde esta fuente** y vuelve atrás.
3. Toca **Instalar**. Si ya tenías Píllalo, se actualiza encima y no pierdes nada.

Android muestra ese aviso con cualquier app que no viene de Google Play. El instalador es el oficial y está firmado por Píllalo.

## Verificar la firma

Todas las versiones están firmadas con el mismo certificado. Su huella SHA-256 es:

```
c00365780167c3d60ed0a1fdb92c142ea9f9a1abd7985329034c4aefe865a7a9
```

Con las herramientas de Android puedes comprobarla así:

```
apksigner verify --print-certs Pillalo.apk
```
